# Sonsuz Çay Demleme Fal Makinesi

## Dünyanın En Ciddi, En Bilimsel ve En Saçma Projesi

Bu repository, insanlık tarihinin en büyük sorularından birine cevap arar: **"Çay demlenirken fal bakılır mı?"**

Cevap: Evet. Sonsuza kadar.

### Özellikler (Abartılı)
- %100 çalışan Python kodu (gerçekten çalışır, deneyin)
- Sonsuz demleme süresi simülasyonu (ama aslında 2 saniye)
- Rastgele, tamamen uydurma ve ikna edici fal yorumları
- Patates içermez. Çay içerir. Simit içerebilir.
- Gizli damga ve resmi imza içerir (ciddi)

### Nasıl Kullanılır?
```bash
python fal_makinesi.py
```

Adınızı girin, çay demlensin, falınızı alın. Sonra unutun.

### Bilimsel Kanıtlar
- Çay yaprakları rastgele hareket eder (quantum çay fiziği)
- Fal %0 doğrudur ama %100 eğlencelidir
- Bu proje Nobel ödülü almamıştır. Henüz.

### Katkıda Bulunma
Lütfen katkıda bulunmayın. Bu proje zaten mükemmel ve saçmadır. Pull request açarsanız falınız kötüleşir.

### Lisans
Bu proje "Sonsuz Çay Lisansı" altındadır. İstediğiniz gibi kullanın, ama çayınızı bitirin.
